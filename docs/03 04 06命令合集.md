# 【Linux RuyiSDK】第 3-4-6 集合辑：ruyi 命令一本通，从入门到熟练

---

哈喽，大家好！这集把 ruyi 的常用命令一次性讲清楚。这篇把基础命令、包管理命令和生态管理命令打包整理，方便查看

---

## 一、基础命令（先认识 ruyi 本身）

```bash
# 看版本，确认安装成功
ruyi --version

# 看帮助，了解所有子命令
ruyi --help

# 更新包索引
ruyi update

# 配置国内镜像源
ruyi config set repo.remote https://mirror.iscas.ac.cn/ruyi

# 遥测数据管理（可选）
ruyi telemetry on    # 同意
ruyi telemetry off   # 退出
```

## 二、包管理命令

```bash
# 查看所有包（包括未安装的）
ruyi list --all

# 按名字过滤，比如找 gnu 相关的工具链
ruyi list --name-contains gnu

# 查看已安装的包（小技巧：用 grep 过滤）
ruyi list | grep installed

# 安装包
ruyi install toolchain/gnu-upstream

# 卸载包
ruyi uninstall toolchain/gnu-upstream

# 下载并解压源码包或 Demo
ruyi extract coremark
ruyi extract -d ./mydir coremark   # 指定解压目录
```
## 三、生态与维护命令

```bash
# 查看社区新闻和公告
ruyi news list
ruyi news read -h
ruyi news read 1	 # 读取特定序号的新闻

# 下载所需系统镜像，并为设备安装系统
ruyi device provision  

# 自我维护
ruyi self clean           # 清理数据目录
ruyi self uninstall	      # 卸载 ruyi 包管理器
ruyi self uninstall --purge	 # 彻底卸载 ruyi 包管理器，包括缓存和安装的软件包
```

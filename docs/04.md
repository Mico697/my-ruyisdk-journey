# 【RuyiSDK 包管理器】 Linux 篇 04：ruyi核心命令
哈喽，大家好！这一集呢，我们会完整的走一遍：搜索包、安装包、验证安装、卸载包的过程，可以独立的去管理ruyi里所有的工具链。

---

## 一、浏览仓库
终端输入
```bash
ruyi list --all
```
第一条命令， ruyi list ，用来查看仓库里有哪些包。

输出很长，包含工具链、模拟器、源码包等各种类型。建议配合  grep  过滤，只看感兴趣的。
按名字过滤：
```bash
ruyi list --name-contains gnu
```

这样只显示名字里带 "gnu" 的包，清爽很多。

查看已安装的包
```bash
ruyi list --all | grep installed
```
或者直接看物理安装目录：
```bash
ls ~/.local/share/ruyi/binaries/x86_64/
```
注：ruyi 更新比较频繁，命令参数可能变化。不要死记参数，报错的时候看看  ruyi --help  或者官方文档。

---

## 二、安装包
第二条命令， ruyi install ，最核心的命令。
安装指定工具链：
```bash
ruyi instal toolchain/gnu-upstream
```
ruyi 会自动从仓库下载、解压、放到正确的位置。整个过程不需要你手动改 `PATH`，不需要配置环境变量。
- 安装过程中的输出 ：
你会看到下载进度条、解压过程、最后提示`Installation complete`。如果网络慢，这个过程可能需要等一会儿，耐心等就行。

- 验证安装：
装完之后，用前面讲的方法确认一下：
```bash
ls ~/.local/share/ruyi/binaries/x86_64/
```
看到对应的文件夹，说明安装成功。

---


## 三、ruyi uninstall：卸载包

第三条命令， ruyi uninstall ，把不用的包删掉。
```bash
ruyi uninstall toolchain/gnu-upstream
```
- 卸载验证：
卸载完再看一眼安装目录：
```bash
ls ~/.local/share/ruyi/binaries/x86_64/
```
对应的文件夹消失了，说明卸载干净。ruyi 的卸载很彻底，不会留垃圾文件。

---


## 四、下载并解压源码包

第四条命令， `ruyi extract` ，用来下载源码包或 Demo 包，并自动解压。
```bash
ruyi extract coremark
```
默认解压到当前目录。如果想指定位置，加  `-d` ：
```bash
ruyi extract -d ./mydir coremark
```
这个命令在获取源码、跑基准测试的时候很有用。比如你想测一下 ruyi 装的工具链性能怎么样，可以  `extract` 一个 `coremark`，然后编译运行。

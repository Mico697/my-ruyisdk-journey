# 【RuyiSDK 包管理器】 Linux 篇 03：ruyi 基础命令

哈喽，大家好！这一集呢我们来认识ruyi的基础命令

---

## 一、确认安装
```bash
ruyi --version
```
第一条命令， `ruyi --version` 。看到版本号弹出来，比如  `Ruyi 0.51.0 `，说明 ruyi 本身安装成功，可以正常工作。
如果这里报错 ` command not found `，说明 `PATH `没配好，或者安装过程出了问题，需要重新安装。

---

## 二、认识所有子命令
终端输入
```bash
ruyi --help
```
第二条命令， ruyi --help 。这里列出了 ruyi 支持的所有子命令。
- `list`：浏览仓库里的包
- `install`：安装包
- `uninstall`：卸载包
- `venv`：创建虚拟环境
- `update`：同步包索引
- `config`：配置管理
- `news`：查看社区动态

其他的命令，比如`device provision`、`extract`、 `self` ，我们后面再慢慢讲。

小技巧：`help` 输出很长，终端里翻页不方便，可以配合  `grep` 过滤。比如只想看和  `list`  相关的：

```bash
ruyi --help | grep list
```
---

## 三、同步包索引
终端输入
```bash
ruyi update
```
第三条命令， `ruyi update` ，这是高频命令。它的作用是从远程仓库拉取最新的包列表，同步到本地缓存。

ruyi 的仓库是动态更新的，新的工具链、新的版本会不断加入。如果你很久没 update，本地看到的包列表就是旧的，可能找不到最新的工具链。
建议：每次安装新包之前，先执行一次  ruyi update ，确保你看到的是最新的仓库状态。

注：输入`ruyi update`后可能会出现`SSL error` 是因为访问Github时网络中断或者不稳定，这是国内访问Github的常见问题，可以多试几次或者更换手机热点

---

## 四、配置管理
终端输入
```bash
ruyi config
```
第四条命令，`ruyi config`，用来管理ruyi的配置文件

```bash
ruyi config get <key>        # 查看配置
ruyi config set <key> <value> # 设置配置
ruyi config unset <key>       # 删除配置
ruyi config remove-section <section> # 删除整个配置块
```
注：
配置文件弄乱了，一键重置最省事
```bash
rm -f ~/.config/ruyi/config.toml
rm -rf ~/.cache/ruyi/reops
ruyi update
```

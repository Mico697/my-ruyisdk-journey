# 【RuyiSDK 包管理器】Linux篇07：从零搭建通用 RISC-V 开发环境，跑通 Hello World

---

哈喽，大家好！这集是实战篇！前面几集把安装和命令都讲完了，这集把它们串起来，从零搭一套能编译、能运行 RISC-V 程序的开发环境。

不需要买开发板，用 QEMU 模拟器就能跑，零成本入门！

---

## 第一步：安装必要组件

```bash
# 更新包索引
ruyi update

# 安装工具链和 QEMU
ruyi install gnu-upstream
ruyi install qemu-user-riscv-upstream
```
## 第二步：创建虚拟环境
```bash
ruyi venv -t gnu-upstream -e qemu-user-riscv-upstream generic ./riscv-env
. ./riscv-env/bin/ruyi-activate
```

## 第三步：写一段C代码

```bash
cat > hello.c << 'EOF'
#include <stdio.h>
int main() {
    printf("Hello, World\n");
    return 0;
}
EOF
```

## 第四步：交叉编译

```bash
riscv64-unknown-linux-gnu-gcc -o hello hello.c
```
用`file`命令验证一下：

```bash
file hello
```

## 第五步：用QEMU运行
```bash
qemu-riscv64 ./hello
```

看到输出`Hello,World!`就搞定了
